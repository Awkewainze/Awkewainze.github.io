# Nova Walseth professional site

## Getting Started

### [mise-en-place](https://mise.jdx.dev)

This is used to manage tool versions, environmental variables, and tasks. It is not required but is useful.

### Commands

To install dependencies:

```bash
mise run install
```

To start a development server:

```bash
mise run dev
```

To build (includes sourcemaps):

```bash
mise run build
```

To build for production (minified):

```bash
mise run build -E production
```
